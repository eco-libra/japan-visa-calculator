# japan-visa-calculator

A web application that helps travelers quickly check whether they need a visa to enter Japan based on their nationality and travel purpose.

## Features

- 🌍 Select your nationality
- ✈️ Choose your travel purpose
- 📅 Check visa requirements
- 📄 Display required documents
- ⚡ Fast and easy-to-understand results

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Claude Code

## Why I Built This

While planning international travel, I noticed that visa information is often scattered across multiple government websites and can be difficult to understand.

This project aims to simplify the process by providing a clear and user-friendly way to check Japan's visa requirements.

## Future Improvements

- Support more visa categories
- Multi-language support (English, Japanese, Spanish)
- Official embassy links
- Save search history
- AI travel assistant
